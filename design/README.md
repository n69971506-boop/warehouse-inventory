# Карта прототипа Figma

Перетащите каждый SVG в Figma Design. Создайте frame шириной 390 и высотой 780 для каждого экрана, поместите в него соответствующий SVG с координатами 0,0.

- Учёт → «Сканировать камерой» → Сканер.
- Для демонстрации поставьте невидимую область на этикетку в рамке сканера и свяжите её с формой подтверждения. В приложении код подставляется в форму после распознавания, название и остаток появляются после «Найти товар».
- Форма подтверждения → вкладка «Закупки» → Закупки.
- Закупки → вкладка «Учёт» → Учёт.
- Верхние вкладки ведут к соответствующим экранам, кнопка возврата сканера ведёт в «Учёт».

В приложении проведение операции показывает результат на форме. Экран «Закупки» открывается отдельной вкладкой.
